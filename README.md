# 校园考勤工作台

从 QQ 邮箱读取照片，校验照片信息，并导出 Excel 报表。
支持班级名单、学生提交统计、请假登记、老师代签和相似照片比对。
页面使用 Streamlit，数据保存在本机 SQLite 数据库中。

[安装与启动](#安装与启动) · [首次配置](#首次配置) · [日常操作](#日常操作) · [故障处理](#故障处理)

## 安装与启动

准备 Git 和 Python 3.11 或更高版本。安装依赖时需要网络连接。
以下命令使用项目虚拟环境，不修改系统 Python 的依赖。

### Linux / macOS

在终端执行：

```bash
git clone https://github.com/woyao75/attendance-bonus.git
cd attendance-bonus
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

### Windows PowerShell

在 PowerShell 执行：

```powershell
git clone https://github.com/woyao75/attendance-bonus.git
cd attendance-bonus
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

### 打开和停止页面

1. 保持终端运行。
2. 在浏览器打开 <http://127.0.0.1:8501>。
3. 按下述步骤完成首次配置。

关闭浏览器不会停止程序。要停止程序，在启动终端按 `Ctrl+C`。
下次使用时，进入项目目录，执行对应系统的最后一条启动命令。
Linux / macOS 也可执行 `./run.sh web`。无需重新安装依赖。
更新代码或依赖后，请停止并重新启动后台。只刷新浏览器可能仍使用旧进程中的模块。

## 首次配置

### 获取邮箱授权码

1. 登录 QQ 邮箱网页版。
2. 打开“设置”，进入“账户”或“账号与安全”。
3. 开启 IMAP/SMTP 服务。
4. 按页面提示生成授权码。

授权码用于连接邮箱。授权码不是 QQ 登录密码。

### 保存校验配置

1. 在左侧展开“邮箱与校验配置”。手机用户先展开侧栏。
2. 填写接收学生邮件的 QQ 邮箱。
3. 填写目标纬度和目标经度。请确认地图坐标与照片 GPS 使用相同坐标系。
4. 填写“距离阈值（米）”。默认值为 `200`。
5. 保留“照片相似度阈值（汉明距离）”的默认值 `5`。
6. 填写 QQ 邮箱授权码。
7. 如需限制拍摄时间，展开“拍摄时间校验”，填写窗口开始和窗口结束。
8. 点击“保存配置”。确认页面显示“配置已保存”。

时间窗口示例：

```text
窗口开始：2026-11-05T08:00:00+08:00
窗口结束：2026-11-05T10:00:00+08:00
照片默认时区：+08:00
```

将两个时间字段都留空，可关闭拍摄时间校验。软件信息和位置校验仍会执行。
修改配置只影响后续新提交。已有照片的基础校验结果不会自动更新。
再次保存时，授权码留空会保留原值。页面不会显示已保存的授权码。

## 日常操作

### 1. 导入学生名单

1. 打开“名单管理”标签页。
2. 展开“学生名单导入”。
3. 点击“下载学生名单模板”。
4. 按模板填写姓名、学号和班级。将学号列设为文本，保留前导零。
5. 上传 `.csv` 或 `.xlsx` 文件。
6. 点击“导入学生名单”。确认页面显示导入结果。

名单示例：

```csv
姓名,学号,班级
张三,0020230001,计算机一班
李四,0020230002,计算机二班
```

列顺序不限。CSV 支持 UTF-8 和 GB18030 编码。
没有班级列的旧名单仍可导入。班级为空的学生归入“未分班”。
同学号、同姓名可更新班级；班级留空会保留原值。
同一学号对应不同姓名时，系统取消本批导入。
更新班级后，历史日期也按当前班级统计。

### 2. 通知学生提交照片

要求学生向已配置的邮箱发送邮件：

| 项目 | 要求 | 示例 |
| --- | --- | --- |
| 邮件主题 | 姓名、半角加号、学号 | `张三+0020230001` |
| 照片附件 | JPG 或 JPEG 原图 | `photo.jpg` |
| 定位信息 | 拍照时开启相机定位权限 | 原图含 GPS 信息 |

请勿使用旧主题 `【打卡】学号-姓名`。系统会跳过主题格式不符的邮件。
截图或压缩后的照片可能丢失定位信息。

### 3. 拉取并核验照片

1. 在左侧点击“一键拉取并校验”。
2. 等待页面显示处理邮件数和新增记录数。
3. 打开“照片核验”标签页。
4. 使用“校验结果”和“照片重复判定”筛选记录。
5. 在“照片预览”区选择记录。
6. 查看原图、校验详情和相似历史照片。
7. 人工核验异常记录。

系统读取收件箱，不改变邮件已读状态。同一邮件附件不会重复入库。
表格每页最多显示 200 条。点击表头可排序当前页。
在表格工具栏中可显示更多列。

### 4. 查看学生考勤

1. 打开“学生考勤”标签页。
2. 选择“统计日期（北京时间）”。
3. 选择“统计班级”。
4. 查看人数和班级汇总。
5. 将“学生提交状态”设为“未提交”，查看未提交名单。

顶部概览按照片计数。学生考勤按所选日期和班级按人计数。
系统使用邮箱服务器收件时间确定统计日期，不使用照片拍摄日期。
同一学生提交多张照片只计一人。名单外提交单独显示。

### 5. 登记请假、代签或补签

1. 在“学生考勤”中选择日期和班级。补签时选择过去的日期。
2. 展开“请假登记 / 老师代签”。
3. 选择“办理学生”。
4. 选择“办理类型”：请假、老师代签或撤销。
5. 填写“经办老师姓名”和“办理原因”。
6. 点击“保存考勤登记”。确认页面显示保存结果。

老师代签计入出勤。请假单独统计。
同一学生同一天以最后一次人工登记为准。
选择“撤销”可恢复照片计算出的状态。历史登记仍会保留。
后续照片不会覆盖生效中的人工登记。经办老师姓名由操作人员填写。

### 6. 导出报表

| 用途 | 生成位置 | 下载按钮 | 范围 |
| --- | --- | --- | --- |
| 照片校验记录 | 左侧“生成并下载报表” | 下载考勤汇总报表 | 全部照片记录；含重复判定 |
| 学生出勤记录 | 学生考勤中的“生成学生考勤报表” | 下载学生考勤报表（含请假和代签） | 当前日期和班级；含未提交、请假及代签 |

先生成报表，再点击下载按钮。页面状态筛选不限制报表范围。

## 校验结果说明

| 术语 | 含义 |
| --- | --- |
| 基础校验 | 校验软件信息、GPS 位置，以及已配置的拍摄时间窗口 |
| 有效 / 校验通过 | 照片通过基础校验；学生通过还要求提交姓名与名单一致 |
| 无效 / 未通过 | 照片未通过基础校验；查看原因后人工核验 |
| 疑似重复 | 照片指纹与更早入库的照片接近；需要人工核验 |
| 校验异常 | 对应校验无法完成；查看原因和日志 |
| 未校验 | 对应校验尚未执行，或缺少照片指纹 |
| 未提交 | 当天没有照片提交，且没有生效的请假或代签登记 |
| 出勤人数 | “校验通过人数”与“老师代签人数”之和 |

照片元数据可以修改。有效不能证明本人到场，疑似重复不能直接认定作弊。
缺少 GPS 也不能直接认定作弊。系统未绑定发件邮箱与学号。
重复判定独立于基础校验，因此同一记录可同时显示“有效”和“疑似重复”。

### 相似照片规则

系统使用 64 位 pHash 作为照片指纹。汉明距离表示两个指纹中不同的位数。
距离小于或等于阈值时，系统标记“疑似重复”。默认阈值为 `5`，允许范围为 `0`～`64` 的整数。
`0` 表示指纹相同，不表示文件字节相同。增大阈值会增加匹配数量，也可能增加误判。

新照片与更早入库的所有可用指纹比较，包括同封邮件、其他学号和其他日期的照片。
系统保存最相似记录的编号和距离。距离相同时，关联最早入库的记录。
比较失败只影响当前记录，后续照片继续处理。

修改阈值后，点击左侧“重新比对历史照片”以更新已有指纹的判定。
此操作不重新下载邮件，也不重新计算旧照片指纹。没有指纹的旧记录仍为“未校验”。
全库比对耗时会随记录数量增加。操作时请等待进度完成。

## 命令行与数据维护

以下命令用于 Linux / macOS。请从项目根目录执行。
Windows 用户将 `.venv/bin/python` 替换为 `.\.venv\Scripts\python.exe`。

```bash
# 生成缺失配置；不覆盖已有文件。
.venv/bin/python -m src.cli init
# 拉取邮件。
.venv/bin/python -m src.cli fetch
# 将照片报表写入项目目录的“考勤汇总报表.xlsx”。
.venv/bin/python -m src.cli report
# 使用已保存的阈值重新比对历史照片。
.venv/bin/python scripts/recheck_photo_duplicates.py
# 仅为本次历史比对指定阈值；不修改配置。
.venv/bin/python scripts/recheck_photo_duplicates.py --threshold 5
# 执行测试；不需要真实邮箱。
.venv/bin/python -m unittest discover -s tests -v
```

旧入口 `mvp_agent.py` 和 `cli.py` 仍支持 `init`、`fetch`、`report`。

### 配置与文件

| 路径 | 内容 |
| --- | --- |
| `config.json` | 邮箱地址和校验参数；字段示例见 [config.example.json](config.example.json) |
| `.env` | `IMAP_AUTH_CODE=邮箱授权码`；示例见 [.env.example](.env.example) |
| `data/attendance.db` | 名单、照片记录、人工登记和邮件处理进度 |
| `attachments/` | 下载的照片 |
| `logs/agent.log` | 运行日志；单份最大 5 MiB，保留 5 份备份 |

授权码只从 `.env` 读取。请勿将授权码写入 `config.json`。
程序启动时自动补充旧数据库缺少的表和字段。
默认附件上限为 10 MiB，邮件上限为 25 MiB。
可在 `config.json` 修改 `max_attachment_bytes` 和 `max_email_bytes`，单位为字节。

### 导入旧 CSV

1. 停止正在修改数据的任务。
2. 备份旧 CSV 和当前数据库。
3. 执行导入命令：

```bash
.venv/bin/python scripts/migrate_csv_to_sqlite.py --csv data/records.csv --db data/attendance.db
```

导入失败时，本批数据不会写入。源 CSV 不会删除。
重复导入相同数据不会新增记录。旧十列 CSV 缺少邮件来源，可能与重新扫描的邮件重复。
旧 `state.json` 不会导入；首次拉取会重新扫描收件箱。

### 备份与分享

1. 停止程序和所有数据写入任务。
2. 复制整个 `data/`、`attachments/`、`config.json` 和 `.env` 到受控备份位置。
3. 恢复时，将这些文件放回相同位置。

备份整个 `data/`，包括存在的 SQLite WAL 文件。
分享项目时，只分享代码和示例配置。不要分享 `.env`、学生数据或照片。
接收者按“安装与启动”创建自己的虚拟环境，再填写自己的配置。

## Linux 后台运行

默认仅本机可访问。以下示例保持此访问范围：

```bash
mkdir -p logs
nohup .venv/bin/python -m streamlit run app.py --server.address=127.0.0.1 --server.port=8501 > logs/web.log 2>&1 &
echo $! > logs/streamlit.pid
```

执行 `tail -f logs/web.log` 查看日志。按 `Ctrl+C` 退出日志查看，不会停止服务。
执行 `kill "$(cat logs/streamlit.pid)"` 停止上述后台进程。`nohup` 不提供开机自启。

如需其他电脑访问，将启动参数改为 `--server.address=0.0.0.0`。
允许防火墙通过 TCP 8501，并访问 `http://服务器实际IP:8501`。
`0.0.0.0` 是监听地址，不能作为浏览器访问地址。
此版本没有登录验证。仅允许可信内网访问，或使用带身份验证的反向代理。

## 故障处理

| 问题 | 处理方法 |
| --- | --- |
| 提示缺少 `openpyxl` 等模块 | 用启动程序的同一个虚拟环境执行 `python -m pip install -r requirements.txt` |
| 邮箱连接失败 | 确认 QQ 邮箱已开启 IMAP；确认填写的是授权码；检查网络能否访问 `imap.qq.com:993` |
| 新增记录为 0 | 检查邮件是否在收件箱；检查主题和附件格式；已处理的附件会跳过 |
| 提示缺少 GPS | 请学生开启相机定位权限，再提交原图；人工核验当前记录 |
| 提示邮件超过大小限制 | 调整 `max_email_bytes`，或将该邮件移出收件箱，再次拉取 |
| 提示任务已运行或有锁文件 | 确认没有写入任务；仅在无任务时删除项目根目录的 `.mvp_agent.lock` |
| 照片无法预览 | 检查 `attachments/` 中的照片是否存在；查看 `logs/agent.log` |
| 页面无法打开 | 检查启动终端；确认端口；使用终端显示的 URL |
| 其他异常 | 查看 `logs/agent.log`；先排除原因，再重试操作 |
