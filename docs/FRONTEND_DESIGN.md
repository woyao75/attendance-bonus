# 校园考勤工作台界面

面向辅导员的本地管理工具。主要工作是拉取学生照片、核验异常、按班级查看提交情况和导出报表。

## 设计约定

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 纸白 | `#FFFFFF` | 数据与照片工作区 |
| 雾蓝 | `#F1F5FA` | 页面底色 |
| 校务靛蓝 | `#274690` | 当前标签、操作焦点 |
| 深墨蓝 | `#182C4D` | 侧栏与主要文字 |
| 提醒琥珀 | `#A65B16` | 异常与疑似重复 |
| 通过绿 | `#235C47` | 已通过的文字状态 |

页头采用本机 Noto Serif CJK SC / 思源宋体，其他内容采用 Noto Sans CJK SC / 思源黑体；
未安装这些字体时回退到操作系统中文字体，不依赖外部字体服务。
全部内容左对齐；只在考勤簿式页头使用宋体，表格与操作保留易读黑体。
状态同时有文字和颜色，不要求用户仅凭颜色识别有效或异常。

## 布局选择

考虑过把所有区块留在单页纵向排列。名单、两组不同计数单位的指标、照片表格会相互推挤，
因此采用一个照片概览和三个工作标签；常用操作在侧栏上方，配置折叠收纳。
页头显示北京时间日期，突出校园考勤簿的文书气质；周围控件保持安静，不添加宣传文案或背景动效。

```text
桌面
┌───────────────┬─────────────────────────────────────────┐
│ 校园考勤       │ 校园考勤工作台                    当日日期 │
│               ├─────────────────────────────────────────┤
│ 拉取并校验     │ 照片提交概览（全部历史，按照片计数）        │
│ 历史照片比对   ├─────────────────────────────────────────┤
│ 生成报表       │ 照片核验    学生考勤    名单管理            │
│ 刷新           ├────────────────────────┬────────────────┤
│               │ 筛选与记录              │ 照片预览        │
│ ▸ 邮箱与配置   │ 默认展示五项常用信息     │ 校验详情        │
│ ▸ 提交说明     │ 其余列由工具栏展开       │ 相似历史照片    │
└───────────────┴────────────────────────┴────────────────┘

手机
┌──────────────────────────┐
│ 展开侧栏                  │
│ 工作台标题与日期           │
│ 两列照片概览               │
│ 三个工作标签               │
│ 筛选与分页                 │
│ 记录表格（区域内滚动）      │
│ 照片预览与关联历史照片      │
└──────────────────────────┘
```

照片概览按照片计数，学生考勤按所选收件日期与班级按人计数。
筛选、选择记录、名单导入和配置输入仍使用 Streamlit 原生控件。
原始哈希收进详情，不要求辅导员理解存储字段或哈希格式。

## 实现位置

- `app.py`：工作区划分、侧栏顺序、常用列与照片详情。
- `src/ui.py`：页头、品牌标记、状态样式、空照片提示。
- `assets/workspace.css`：布局、颜色、字体、键盘焦点与手机适配。
- `.streamlit/config.toml`：整体主题、侧栏主题及面向使用者的工具栏。

## 验证与复核

现有 95 项测试覆盖邮件拉取、配置保存、名单与班级筛选、分页、报表和照片关联预览。
使用独立的 `/tmp` 示例数据库与隔离的 Edge 无头浏览器检查，不把示例数据导入实际数据库。
示例截图中的姓名、名册和校园插图均为测试内容。

检查宽度为 320、768、1024、1440px，页面均无横向溢出和浏览器脚本错误。
桌面显示表格与照片双栏；平板及手机改为上下排列，手机概览与人数指标排成两列。
实际操作验证了异常筛选、空结果、班级切换、说明折叠、手机侧栏与配置表单。
Tab 键可移动到带标签的筛选控件，焦点轮廓为 3px。
照片核验、学生考勤、名单管理与手机配置表单通过 axe WCAG 2.1 AA 规则扫描；
自动检查不替代人工读屏验证。

修正了 Streamlit 默认 caption 透明度叠加导致的对比度不足。
说明文字使用 `#586780`，侧栏说明使用 `#B7C7E1`，透明度设为 1。
照片与关联历史照片提供替代文字；为使用原生 `st.image(alt=...)`，Streamlit 最低版本调整为 1.66。
旧环境需重新执行 `.venv/bin/python -m pip install -r requirements.txt`。
不使用自动播放动效，并尊重 `prefers-reduced-motion`。

## 本次展示优化约定

延续现有蓝白工作台，不引入外部参考站点、字体或图片服务。以现有照片核验、学生考勤和名单管理三屏为参考：
照片核验保留筛选与表格并排预览，学生考勤将八项指标分为提交统计与人工登记，名单管理保留模板导入流程。

- 页面任务：帮助老师迅速发现异常、查看照片和确认班级提交情况。主要操作保持“一键拉取并校验”。
- 信息层级：历史照片总览明确计数范围；选中照片的校验结果与原因放在原图上方；人数统计与照片统计明确区分。
- 视觉：使用既有深墨蓝、校务蓝、提醒琥珀与通过绿；浅色工作区、细边框、8px 控件圆角；间距使用 4px 倍数。
- 窄屏：桌面保留记录与原图双栏；工作区不足时改为上下排列。指标在手机上排成两列，表格只在自身区域内滚动。
- 状态：保留原生加载、成功、错误、空结果提示；基础校验状态使用文字、符号和颜色共同表达；保留疑似重复的独立提示。
- 可访问性：沿用原生输入控件，保留键盘焦点、侧栏展开入口和表格工具栏；不隐藏操作标签，不使用装饰动效或大幅宣传区。
