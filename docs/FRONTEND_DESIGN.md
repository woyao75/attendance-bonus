# 校园考勤工作台界面

面向辅导员的本地管理工具。主要工作是拉取学生照片、核验异常、按班级查看提交情况和导出报表。

## 设计约定

| 色彩 | 值 | 用途 |
| --- | --- | --- |
| 纸白 | `#FFFFFF` | 数据与照片工作区 |
| 雾蓝 | `#F1F5FA` | 页面底色 |
| 校务靛蓝 | `#274690` | 当前标签、操作焦点 |
| 深墨蓝 | `#182C4D` | 侧栏与主要文字 |
| 提醒琥珀 | `#A65B16` | 异常与疑似重复 |
| 通过绿 | `#235C47` | 已通过的文字状态 |

页头采用本机 Noto Serif CJK SC / 思源宋体，其他内容采用 Noto Sans CJK SC / 思源黑体；
未安装这些字体时回退到操作系统中文字体，不依赖外部字体服务。
全部内容左对齐；只在考勤簿式页头使用宋体，表格与操作保留易读黑体。
状态同时有文字和颜色，不要求用户仅凭颜色识别有效或异常。

## 布局选择

考虑过把所有区块留在单页纵向排列。名单、两组不同计数单位的指标、照片表格会相互推挤，
因此采用一个照片概览和三个工作标签；常用操作在侧栏上方，配置折叠收纳。
页头显示北京时间日期，突出校园考勤簿的文书气质；周围控件保持安静，不添加宣传文案或背景动效。

```text
桌面
┌───────────────┬─────────────────────────────────────────┐
│ 校园考勤       │ 校园考勤工作台                    当日日期 │
│               ├─────────────────────────────────────────┤
│ 拉取并校验     │ 照片提交概览（全部历史，按照片计数）        │
│ 历史照片比对   ├─────────────────────────────────────────┤
│ 生成报表       │ 照片核验    学生考勤    名单管理            │
│ 刷新           ├────────────────────────┬────────────────┤
│               │ 筛选与记录              │ 照片预览        │
│ ▸ 邮箱与配置   │ 默认展示五项常用信息     │ 校验详情        │
│ ▸ 提交说明     │ 其余列由工具栏展开       │ 相似历史照片    │
└───────────────┴────────────────────────┴────────────────┘

手机
┌──────────────────────────┐
│ 展开侧栏                  │
│ 工作台标题与日期           │
│ 两列照片概览               │
│ 三个工作标签               │
│ 筛选与分页                 │
│ 记录表格（区域内滚动）      │
│ 照片预览与关联历史照片      │
└──────────────────────────┘
```

照片概览按照片计数，学生考勤按所选收件日期与班级按人计数。
筛选、选择记录、名单导入和配置输入仍使用 Streamlit 原生控件。
原始哈希收进详情，不要求辅导员理解存储字段或哈希格式。

## 实现位置

- `app.py`：工作区划分、侧栏顺序、常用列与照片详情。
- `src/ui.py`：页头、品牌标记、状态样式、空照片提示。
- `assets/workspace.css`：布局、颜色、字体、键盘焦点与手机适配。
- `.streamlit/config.toml`：整体主题、侧栏主题及面向使用者的工具栏。

## 验证与复核

现有 85 项测试覆盖邮件拉取、配置保存、名单与班级筛选、分页、报表和照片关联预览。
使用独立的 `/tmp` 示例数据库进行 Firefox 实际浏览器检查，不把示例数据导入实际数据库。
示例截图中的姓名、名册和校园插图均为测试内容。

桌面检查宽度 1440px，手机检查宽度 390px，页面均无横向溢出和 Streamlit 页面异常。
首次手机截图发现页头被工具条遮挡，已增加顶部间距；复核后标题位置为距顶部 80px。
手机表格和照片工作区按上下顺序排列，保留区域内表格滚动。
说明文字实测颜色为 `#586780`，侧栏说明为 `#B7C7E1`；键盘 Tab 焦点可见。
不使用自动播放动效，并尊重 `prefers-reduced-motion`。
