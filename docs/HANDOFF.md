# 交付与人工验收记录

## 本轮实现

- 会话：scrypt 密码哈希（N=32768、r=8、p=3）、随机会话令牌，仅保存令牌 SHA256；HttpOnly Cookie，生产 Secure，8 小时过期；退出、改密、停用和重置使会话失效；IP 限流与账户失败锁定。
- 权限：写请求同源校验和自定义头防 CSRF；学生身份取自会话；辅导员创建任务必须拥有班级权限，任务访问按发布人限制；管理员有全局管理权。
- 数据：班级、辅导员关联、固定成员名单、发送队列、审计记录；保留初始迁移，新增 MySQL 8.0 升级迁移，旧用户无密码时不能登录。
- 邮件：持久化队列、退避重试 5 次、稳定 Message-ID、签名 JSON、照片 SHA256、条件更新防止旧邮件回退审核；邮件 worker 独立部署，数据库写入失败不标记已读。
- 照片：上传限制、解码验证及 JPEG 重编码，受保护的照片接口，原公开 `/uploads` 路由关闭。历史照片保留，等待学校确定保留期限。
- 前端：统一登录、首次改密、本人任务列表、后置摄像头、定位新鲜度与精度校验、拍摄瞬间冻结定位、重拍、状态轮询；管理员班级/账号/CSV 导入/停用/重置/调班；辅导员任务发布/审核/归档/导出。
- PWA：静态文件预缓存和构建版本；API/照片不缓存；离线提示；PNG 安装图标；推送仅保留处理器，尚无订阅与服务端发送。
- 运维：Compose 五个服务（数据库、迁移、API、worker、Caddy）、持久卷、HTTPS、就绪探针、日志轮转、备份脚本和 CI。

## 验证边界

本地验证使用独立 MySQL 8.0.45 实例、随机测试账号和本机浏览器模拟摄像头。没有使用真实学生照片，没有向真实邮箱发送测试邮件，也没有部署到外部服务器。

自动测试检查：认证/权限、照片隔离、名单快照、图片与围栏校验、SMTP 失败重试、签名 MIME 解析与幂等、重拍与迟到邮件、并发审核、Excel/ZIP 内容、退出/重置/改密/停用导致会话失效。浏览器测试检查登录、首次改密、相机画面、重拍、拍摄位置绑定、提交、创建班级和退出。

2026-09-23 本地验证结果：

- 前后端 TypeScript 检查、生产构建通过。
- 15 项测试通过，包含真实 MySQL 8.0.45 集成测试、校园共享网络下的登录配额隔离、北京时间导出和任务状态推进。
- 旧数据库升级测试通过：角色、班级、已通过记录、历史时间和任务名单保留。
- 迁移后的 MySQL 数据库与当前 Prisma Schema 比较无差异。
- Edge 无界面浏览器流程通过：首次改密、登录、相机、重拍、拍摄位置绑定、提交、审核、归档、创建班级、退出；无页面脚本错误。

## 仍需你提供或人工确认

1. 正式服务器与域名、专用 SMTP/IMAP 授权码。请填入环境文件，不要把凭据提交 Git。
2. 学生/辅导员/班级名单、WGS84 学校坐标和围栏半径，照片保存期限及管理制度。
3. 真机测试：Android / iPhone 后置相机、精确位置权限、安装 PWA、退后台恢复。
4. 专用邮箱完整链路验收，服务器上 Docker 构建和 HTTPS 验证，备份恢复演练与外部监控告警。

当前明确限制：单 API + 单 worker；仅一个归档邮箱；任务列表最多最近 200 条，学生导入每批 100 人；辅导员访问自己发布的任务；历史任务无发布人时仅管理员可管理；CSV 代替原生 XLSX 导入；没有统一身份认证、OSS、逆地理编码、完整 Web Push、人脸/活体识别。水印和浏览器 GPS 不能证明客户端未被篡改。

当前目标已调整为单机本地版：管理员电脑运行 API、Web 和 IMAP worker，学生直接向归档邮箱发打卡邮件。`LOCAL_EMAIL_MODE=true` 时不需要 SMTP 代发和邮件签名；本地直收邮件必须匹配学生预登记邮箱、任务成员快照姓名、任务 ID 和每人独立的 32 位验证码。该模式仍不能验证客户端 GPS 或邮件内容未被修改。
